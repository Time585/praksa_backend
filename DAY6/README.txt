Ovaj projekat je osnovni login za websajt.
On korisiti bazu podataka koja se drži u phpMyAdmin.
Korišten je phpMyAdmin u skolpu sa XAMP-om.
File s treba prebaciti u htdocs folder XAMP aplikacije kako bi radio,
i mora se u searchbar browser-a ukucati localhost/DAN?/index.php kako 
bi se pristupilo projektu.

Baza kreira table korisnik koji definiše šta jeste i nije null.
Uključuje dio koji mjenja charset da prihvati naša slova.
Koristi insert into da napravi par prototip korisnika.
